## ⚠️ Только LSI в lede (не отдельная посадочная)

Использовать **синонимами** в `lede` SUBPAGES, без новых страниц:

- комплексная информатизация здравоохранения  
- автоматизация медицинских учреждений  
- цифровизация больницы  
- программное обеспечение для клиник  
- эффективность работы больницы с IT  
- ROI автоматизации (только если есть кейс/цифры с согласия клиента)

## ❌ Не добавлять (другая ниша)

**Фармзавод / производство:** MES, ERP фармкомпании, WMS склада, сериализация, Track&Trace, GMP IT, валидация ПО фарма, LIMS, рецептуры, ЭДО лаборатории, роботизация фармпроизводства.

**Больницы / поликлиники:** МИС, электронная медкарта, запись к врачу, регистратура, PACS, ЛИС, учёт услуг, интеграция 1С с МИС, сервер для больницы, 152-ФЗ, отчётность Минздрава, лизинг МИС, тендеры на ПО для здравоохранения.

**Узкие клиники:** стоматология, скорая, прививки, диспансеризация (гос.).

**Проблемные без услуги:** как выбрать МИС, электронный рецепт (гос.), очередь в регистратуру, аккредитация медПО.

**Технологии без продукта:** блокчейн в медзаписях, IoT в медицине (общий), машинное обучение для диагностики (клиническая диагностика не наша услуга).
