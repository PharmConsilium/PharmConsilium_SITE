# Яндекс.Вордстат · семантика для ФармКонсилиум

Регион: **Беларусь**. Период: последние 3–6 мес. (или год для стабильных B2B-запросов).

Частоту брать только из интерфейса Вордстата («"фраза"» — точное вхождение). **Не выдумывать цифры в коде** — только в `deploy/semantic-core.csv`.

---

## A1. Инструкция для заказчика (если есть доступ)

1. Открыть [wordstat.yandex.ru](https://wordstat.yandex.ru), войти под аккаунтом с доступом.
2. Справа выбрать регион **Беларусь**.
3. Для каждой фразы из списка ниже ввести запрос в **кавычках** и записать столбец «Частота " "!» в таблицу.
4. Открыть «Похожие» / «Популярные» — отобрать 3–10 релевантных уточнений на запрос (без розницы ЛС, без других стран, без вакансий).
5. Классифицировать тип: **коммерческий** (услуга/внедрение), **информационный** (что такое), **имидж** (бренд).
6. Передать файл агенту или обновить `semantic-core.csv` (колонка `частота`).

## A3. Правила внесения в проект (после согласования)

1. Один главный запрос на страницу; ключ в **начале title** и в **первых ~120 символах description**.
2. LSI и синонимы — в `lede` SUBPAGES, без переспама (не более 2–3 точных вхождений на экран).
3. Не добавлять `<meta name="keywords">`.
4. Правки только: `js/data/seo-meta.jsx`, при необходимости `js/data/subpages-data.jsx` / `portfolio-data.jsx`.
5. **Google:** через 4–6 недель после деплоя сравнить с отчётом **Search Console** (запросы → страницы) и скорректировать title/description.
