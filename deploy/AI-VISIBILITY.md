# Видимость для ИИ-поиска · ФармКонсилиум

Цель: чтобы ассистенты (ChatGPT, Perplexity, YandexGPT и др.) корректно цитировали бренд и услуги **без** SEO-спама и без правок вёрстки.

---

## 1. llms.txt

Файл в корне: `/llms.txt`

- Краткое описание компании и **ссылки на разделы** (не список ключей столбиком).
- Обновлять при добавлении ключевых услуг или смене канона.

Проверка: `curl -I https://pharmconsilium.by/llms.txt` → 200.

---

## 2. Schema.org (JSON-LD)

В `index.html` (статически):

- `Organization` — название, logo, email, телефон, страна BY
- `LocalBusiness` — адрес (NAP футера), часы `Mo-Fr 09:00-19:00`

**FAQPage** — только после согласования текстов с заказчиком (юридически точные ответы). Не добавлять выдуманные FAQ.

При необходимости `Service` / `WebPage` на отдельные URL — отдельная задача, без дублирования H1 на странице.

---

## 3. Контент для цитирования

ИИ опираются на:

- Уникальные **lede** и блоки «О чём это» в SUBPAGES
- Портфолио с конкретикой (без выдуманных метрик)
- Единый NAP в футере

Не делать:

- Столбцы ключевых слов в llms.txt
- Fake «№1 в Беларуси»
- Скрытый текст для ботов

---

## 4. robots.txt и AI-краулеры

Текущая политика: **Allow: /** для всех (см. `robots.txt`).

Опционально (решение в `LAUNCH.md`):

```
User-agent: GPTBot
Disallow: /

User-agent: Claude-Web
Disallow: /
```

**Рекомендация для B2B лидогенерации:** оставить **Allow** для основных ботов, чтобы бренд находился в ответах; ограничивать только при требовании compliance.

---

## 5. Тесты после деплоя (через 2–4 недели)

Задать в 3 системах (записать дату и скрин):

1. «Кто такой ФармКонсилиум в Беларуси?»
2. «CRM для медицинских представителей Беларусь»
3. «Внедрение CLM фармацевтический маркетинг»

Ожидание: в ответе есть `pharmconsilium.by` и релевантный раздел (`/marketing/crm`, `/marketing/clm`).

---

## 6. Связь с Вордстатом

Семантика для людей (Яндекс/Google) и для ИИ пересекается, но **частоты** только в `semantic-core.csv` после Вордстата. ИИ-тесты — качественные, не замена Метрике/GSC.
